For dealers

Reseller API

Add playlists to a customer's Emberplay device by its MAC address, straight from your billing panel, Telegram bot or script. No need to open the dealer panel.

Getting started

  1. Ask your master dealer to switch on API access for your account.
  2. In the dealer panel, open API keys (the key icon) and create a key. It is shown once, so copy it straight to your server.
  3. Send requests to https://api.emberplay.stream.

Server-to-server only. Never put your key in a web page, a browser fetch() or a mobile app. Anyone who sees it can add playlists in your name. If a key leaks, revoke it in the panel. It stops working at once.

The device must have opened Emberplay at least once, so that it has checked in. New playlists show up in the app's playlist switcher on its next check-in.

Authentication

Send the key in the Authorization header:

Authorization: ApiKey emb_live_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

Bearer emb_live_… also works. MAC addresses can be written AA:BB:CC:DD:EE:FF, aa-bb-cc-dd-ee-ff or AABBCCDDEEFF.

Add playlists

POST/api/v1/devices/{mac}/playlists

Adds 1 to 10 playlists. Playlists already on the device stay where they are, so whatever the customer is watching keeps playing. A playlist that is already there is skipped: for Xtream, the same server and username; for M3U, the same URL.

# Xtream Codes
curl -X POST https://api.emberplay.stream/api/v1/devices/AA:BB:CC:DD:EE:FF/playlists \
  -H "Authorization: ApiKey $EMBERPLAY_KEY" \
  -H "Content-Type: application/json" \
  -d '[
    { "name": "Main",   "type": "xtream", "server": "http://host:8080", "username": "u", "password": "p" },
    { "name": "Backup", "type": "m3u",    "url": "http://host/get.php?username=u&password=p&type=m3u_plus",
      "epgUrl": "http://host/xmltv.php" }
  ]'

Fields

TypeFields
"xtream"name, server (http/https base URL), username, password
"m3u"name, url, optional epgUrl
nonename, url as "host|username|password", read as Xtream

Names are 1 to 60 characters; URLs are http or https, up to 2048 characters. Unknown fields are rejected.

Response 200

{
  "mac": "AA:BB:CC:DD:EE:FF",
  "mode": "append",
  "added":   [ { "id": "1762412345678901234", "name": "Main", "type": "xtream" } ],
  "skipped": [ { "name": "Backup", "reason": "duplicate" } ],
  "claimed": true
}

claimed is true when this request made you the device's owner (see Ownership & locks).

Replace playlists

PUT/api/v1/devices/{mac}/playlists

Same body as POST, but removes every playlist already assigned to the device first. The first one in your list becomes active on the next check-in. Only for devices you own.

Read a device

GET/api/v1/devices/{mac}/playlists

Status and assigned playlists of a device you own. Passwords and M3U URLs are always hidden.

{
  "mac": "AA:BB:CC:DD:EE:FF",
  "ownedByYou": true,
  "activated": true,
  "activationExpiresAt": "2027-11-06T10:00:00.000Z",
  "lastSeenAt": "2026-11-06T09:58:12.000Z",
  "appVersion": "1.3.0",
  "playlistLocked": false,
  "playlists": [
    { "id": "1762412345678901234", "name": "Main", "type": "xtream",
      "server": "http://host:8080", "username": "u", "password": "****" }
  ]
}

Clear playlists

DELETE/api/v1/devices/{mac}/playlists

Removes every assigned playlist from a device you own.

Ownership & locks

  • Your device: you can add, replace, read and clear.
  • A new device (no owner, no playlists yet): your first add or replace makes you its owner.
  • Another dealer's device: you can only add, and only if that dealer has not locked its playlists. You can't replace, read or clear it. To you it looks like it doesn't exist.

Lock a customer's device in the dealer panel to stop other dealers adding playlists to it.

Errors

Errors come back as {"error": {"code", "message", "field"?}}.

StatusCodeMeaning
400invalidBad input; field says which, e.g. [0].url or mac
400too_many_playlistsThe device would have more than 30 playlists
401unauthorizedMissing, wrong or revoked key
403api_disabledAPI access is switched off for your account
403device_not_registeredThe device has never opened Emberplay
403lockedThe owning dealer locked this device's playlists
403not_ownerOnly the owner can replace a device's playlists
404not_foundNo such device among yours (read/clear)
429rate_limitedToo many requests; wait Retry-After seconds

Limits

  • 60 requests per minute and 2,000 per day, per key.
  • 1 to 10 playlists per request, 30 per device.
  • Up to 10 active keys per dealer account.

Moving from Hot Player

Your existing integration works with two changes: the base URL and the key. Hot Player's path is accepted as-is:

POST https://api.emberplay.stream/api/v1/reseller/add-playlists/{mac}
[ { "name": "Main", "url": "http://host:8080|username|password" } ]
